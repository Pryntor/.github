# Pryntor

Pryntor (Pty) Ltd is a South African technology company, registered with CIPC as 2025/946025/07. We work on AI governance: we test what AI chatbots and AI agents promise customers, and help businesses make AI at work answer to someone.

Website: [pryntor.co.za](https://pryntor.co.za)
